# FSFM Studio V16.9

V16.9 completes the first full Vista-window experience and deepens the Night Workshop Studio.

## Vista
Vista blocks using Vista window variants render as Aero-style windows with glass titlebars, icons, minimise and close controls. Titlebars support pointer dragging and arrow-key nudging. Positions persist per page in the current browser. Hidden windows appear in a small dock with Restore and Reopen actions. The Vista site menu is layered above the windows. The homepage desktop keeps its existing window system.

## Studio
Inactive pages use the clearer Activate action. The visible template name and page group are Vista; the internal template key and page routes remain unchanged for compatibility. Enum-backed values use dropdowns for component variants, group layout, wallpaper mode, wallpaper presets, rotation, image position and fit, button/divider styles, and alignment. Wallpaper choices load from the real catalogue. Page creation uses a guided modal form. Errors explain common network, stale-save, validation, missing-file, oversized-upload and server failures. The Night Workshop surfaces, forms, dropdowns and alerts receive a deeper visual polish.

## Publishing
All work remains on \`v16-tinacms-prototype\`. Local saves remain separate from live publishing. No production merge or deployment is performed.
